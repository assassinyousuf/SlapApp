# 💥 SlapApp

A brutally simple, heavily stylized, and physically responsive Flutter application designed to do exactly one thing:
**React when you smack your phone.**

## 🌟 Features
- **Hyper-Realistic 3D Orb UI**: Built with advanced kinetic flutter animations, volumetric shading, and glassmorphic overlays. The central UI core dynamically "breathes" while armed, and physically squashes/stretches elastically upon impact.
- **Pure Physics Detection**: Utilizes raw unadulterated `accelerometer` hardware polling with a tightly tuned 25.0 G-force math algorithm. It completely isolates real smacks from hand jitter without failing on cheap sensors.
- **Randomized Meme Audio**: Features a massive array of randomly rotating classic funny sound effects automatically injected, including:
  - 💥 Vine Booms / Explosions
  - 💨 Verbose Farts
  - 🦆 Cartoon Quacks
  - 🐢 Turtle Moans
  - 🔔 Taco Bell Bongs
  - 🗿 The "Bruh" Effect
  - And much more...

## 📱 How to Use
1. Launch the app and wait exactly 1.0 second for the epic entrance animation.
2. Ensure your volume is turned all the way up.
3. Slap, smack, or violently drop your device on a soft surface.
4. Enjoy.

## 🛠️ Built With
- **Flutter** & **Dart**
- `flutter_riverpod` (State Management)
- `audioplayers` (Hardware low-latency sound emission)
- `sensors_plus` (Kinetic polling)

## ⚠️ Disclaimer
Please do not completely destroy your device testing this app. The threshold is calibrated for a *firm tap*. Breakage or shattering is entirely on you!
